# OmniFile Studio landing page

Static HTML + Tailwind CSS (v3) + Lucide icons. No framework, no bundler.

## Setup
1. `npm install`
2. Set `APP_URL` at the top of `src/main.js` to your deployed app.
3. `npm run build` (writes `dist/styles.css`). Use `npm run dev` while editing.
4. Open `index.html`, or `npm run serve`.

Deploy the folder as-is to Netlify, Vercel, Cloudflare Pages or GitHub Pages.
Run `npm run build` first so `dist/styles.css` is current.
